# Gaussian Processes and Kernel Methods

**Directed Reading Program | University of Washington**  
**Fall 2024**  
**Student:** Yan Peng  
**Mentor:** Yuhan Qian

## Overview

This directed reading project explored Gaussian Processes (GPs), kernel methods, and their applications in statistical modeling and platform trials.

The study covered the connections between linear regression, Bayesian regression, Gaussian Processes, and Kernel Ridge Regression (KRR), along with the potential use of GPs to incorporate non-concurrent control data in platform trials.

## Methods and Implementation

- Studied Gaussian Process regression and kernel-based prediction.
- Implemented Kernel Ridge Regression in R using an RBF kernel.
- Explored the effects of kernel bandwidth and regularization on model predictions.
- Examined uni-task and multi-task GP models for incorporating non-concurrent controls in platform trials.

## Materials

- `KRR.R` — R implementation and simulation of Kernel Ridge Regression.
- `Introduction_to_Gaussian_Processes.pdf` — Presentation on GP theory and its connection to kernel methods.
- `GP_Platform_Trials.pdf` — Presentation on non-concurrent controls and GP applications in platform trials.

The repository contains selected study materials and demonstrations rather than a complete implementation of the platform trial models.
